## 1. 官方文件與條款（可引用）

### 1.1 Google Colab 免費版的行為邊界

- 來源：Google Colab FAQ，`https://research.google.com/colaboratory/faq.html`，核對日 2026-11-03。
- 條文支持的四件事：
  1. 免費版 notebook 最長可跑 12 小時，實際取決於可用性與使用型態。
  2. 閒置會逾時；資源與 GPU 類型「不保證、不無限」，且會隨時間變動。
  3. Colab **不公布**額度、閒置時限與最長 VM 壽命的具體數字，因為它們會變。
  4. 免費版明確不接受「繞過 notebook 介面、主要透過網頁介面操作」與遠端控制（SSH、遠端桌面）；FAQ 直接寫出使用 web UI 做內容生成的用戶，在免費版常見執行階段被終止。

第 4 點是本週教材的關鍵判斷：**把 ComfyUI 的網頁介面當平台長時間使用，在免費版是被條款點名的行為**。條款沒有禁止打開介面，也不會保證它跑完。頁面因此在 W10 第 01 步寫明「短時間按幾次、看圖比對可以；整批長跑回 notebook 送」，卡點表第 8 條寫同一件事，W15 第 01 步再把批次與逐頁的代價並列。三處說法一致，不互相矛盾。

### 1.2 Wan2.2 的授權與硬體下限

- 來源：ComfyUI 官方教學，`https://docs.comfy.org/tutorials/video/wan/wan2_2`，核對日 2026-11-03。
- 支持：Wan2.2 系列以 Apache 2.0 釋出、允許商用（保留著作權聲明與授權條文）；5B 混合模型在 8 GB 顯卡可用原生 offloading 執行；模型分放 `diffusion_models`、`text_encoders`、`vae`，並列出本課使用的三個檔名。
- 未採用的部分：14B 版本的實際顯卡需求，官方頁面未給等價的明確下限，本次也沒有量測，因此教材只走 5B，不對 14B 下任何數字。

### 1.3 插畫模型的授權不是「可商用」三個字

- 來源：`https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/main/LICENSE.md`，核對日 2026-11-03。
- 支持：SDXL 採 CreativeML Open RAIL++-M；RAIL（Responsible AI License）是授權家族名稱，條文附使用限制（use-based restrictions），與 Apache 2.0 的寬鬆程度不同。教材因此把「工具免費」與「模型可否商用」寫成兩件事，要求學生把授權名稱與核對日期放進交接包。

## 2. 課堂實測（measured）

- 方法：`pilot/colab-animated-picturebook.ipynb`，Colab 免費版、T4、2026-10-29 執行。影片 1280×704、49 幀、20 步；插畫 30 步。逐頁計時由 notebook 自身輸出，非人工碼錶。
- 值：
  - 模型四檔合計 23.35 GiB（9.31＋6.27＋1.31＋6.46），下載 280 秒。
  - 插畫約 27 秒／張。
  - 動態逐頁 619、588、585、585、588、588、586、582 秒，合計 4721 秒（78.7 分鐘）。
  - 第 1 頁比其餘多 31–37 秒，差額來自首次把模型載入記憶體。

## 3. 由實測值推算（calculated，非量測）

- 分八次跑、每次換一台新機器：8 ×（280＋619）＝ 7192 秒 ≈ 120 分鐘。
- 一次跑完：280＋4721 ＝ 5001 秒 ≈ 83 分鐘。
- 兩者差 37 分鐘，全部來自換機器要重新下載與載入，不是來自「排隊」這個動作。同一天在同一台機器上分開送八次，不會多花這些時間；頁面因此把差別寫成「斷線損失多少」，不寫成「哪一種比較快」。這兩個數字是設想（用實測值相加），頁面標成設想，不標成推算。

## 4. 課堂建構的參數（constructed）

以下不是研究結果，是教學設計，頁面不得寫成實證：

- 180 分鐘＝60 講授＋120 動手，是本校上課時段的安排，不是量測結果。
- 八週的講授內容與交出項目，是依既有 18 週主題（未更動）排出的配比。
- 每週只加一個工具操作的順序，依「那週任務需要什麼」決定：W09 要出圖、W10 要換視角、W11 要換模型、W12 要讀錯誤、W13 要改尺寸、W14 要出影片、W15 要批次、W16 要交接。

## 5. 被排除的說法與理由

| 說法 | 出處型態 | 排除理由 |
| --- | --- | --- |
| 「免費版閒置 90 分鐘會斷線」 | 部落格、YouTube 教學 | Colab FAQ 明說不公布閒置時限。寫出具體分鐘數等於發明數字；頁面改寫「官方不公布，會逾時」。 |
| 「上課常有人看到 GPU 字樣以為在跑」 | 自己推想的課堂場景 | 沒有實際發生紀錄。改寫成機制說明：notebook 會把輸出存進檔案，所以打開就有字；要看執行編號才知道這次跑了沒。 |
| 「Colab 免費版可以商用」 | 論壇討論 | 混淆了兩件事：執行額度與模型授權。頁面拆成兩段寫，並要求記錄授權條文。 |
| Colab 付費方案與 Comfy Cloud 的價格 | 商業頁面 | 本次未逐項核對當期價格。頁面只標「付費」，不寫金額；要寫價格必須另做一次核對並記錄日期。 |
| 「14B 模型 T4 也跑得動」 | 社群說法 | 官方只給 5B 在 8 GB 可跑的說明，且本次未量測 14B。不寫。 |
| 「網頁介面比較好用，就都用網頁」 | 直覺 | 與 1.1 第 4 點衝突。使用者體驗的取捨不能蓋過條款事實。 |

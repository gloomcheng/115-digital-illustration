# W02 插畫與繪本的藝術史：來源查證紀錄

## 目的

這一週的頁面是依據課堂錄音整理的，但口述內容有多處與史料不符。本檔記錄每個事實主張的查證結果，讓後續修訂不必重做一次查證，也讓「為什麼頁面這樣寫」有線索可循。頁面上每個數字、年代與成分都掛有編號，對應 `src/pages/weeks/2.astro` 的 `footnotes` 陣列。

- 查證日期：2026-09-29
- 覆蓋範圍：洞穴壁畫、死者之書、《凱爾經》、貝里公爵時禱書、中世紀透視與瘟疫、杜勒
- 查證優先序：法國文化部等官方機構頁面 → 大都會藝術博物館等館方記錄 → 出版原文 → 百科條目（僅在無其他可載來源時使用）

## 查不到原始依據而不放進頁面的說法

- 「死者之書」有權威單一版本：確認不成立，頁面改為說明此說法本身錯在哪裡
- 阿爾塔米拉 2023 年發現新彩繪獅子：查無此事，實際是 2024 年新增 23 個動物圖像與 2025 年重新定年，故未寫入
- 死者之書「數千份」的具體數字：無可引用來源，頁面只用「約 192 則咒語、現存數百份」
- 凱爾經與迪士尼城堡、時禱書與貝里公爵的寵物數量等延伸連結：非本週教學重點，未寫入

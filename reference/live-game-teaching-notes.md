# W03 課堂遊戲：老師操作筆記

這份文件不進教材頁面。

## 上課前五分鐘

**視窗一：開遊戲**

```
bun run live
```

印出一個四位數房號，投影給學生。

**視窗二：開外部網址**

```
ngrok http 8787
```

ngrok 印出的 `https://xxxx.ngrok-free.app` 才是給學生的，不是 localhost。確認能載入後把網址投影出去。

**視窗三：老師端**

瀏覽器開 `http://localhost:8787/t`。推進回合、公布比例、抽理由上投影、匯出結果。

**投影機**：另開視窗 `http://localhost:8787/p`。只有比例長條，沒有題目。

## 現場流程

一回合一題，大約五分鐘：

1. 按「開這一題」，學生手機出現題目和選項
2. 學生選一個、寫一句理由、送出
3. 等三十秒到一分鐘
4. 按「公布比例」，投影顯示長條
5. 從理由清單點一句，投影顯示，讓全班回應
6. 按「進入下一題」

第 5 步是重點。答案來自同學不是老師。

## 六個回合

| 回合 | 在練什麼 |
| --- | --- |
| 1 砍圖（條件模糊） | 學生會發現「最可愛」等於沒回答 |
| 2 砍圖（條件明確） | 條件問清楚，答案才浮現，而且三個都對 |
| 3 追問爛需求 | 客戶說的和要的不是同一件事 |
| 4 A2 完稿 | AI 出畫面不出完稿，這是初級職缺縮小的原因 |
| 5 權利範圍 | 連回 W01 契約三行 |
| 6 辨識點 | 縮到 3 公分還在的才是辨識點 |

第 1、2 回合接著跑，不要停太久。學生的落差感是這堂課的 punch。

## 事後匯出

老師端按「匯出學生作答」，得到每個學生每回合的選項、理由、比例。存進學生工作檔案，老師端也留一份，下週開課前看全班在哪幾題分歧最大。

## 如果連不上

- 「房號不存在」：房號每堂課重新產生，確認投影上的是當下的
- 打不開 ngrok 網址：確認網址投影出來了、拼字完整
- 同時連太慢：免費層有頻寬限制，改成提早關答案、老師手動唸比例

## 不要做

- 不要在投影顯示題目。`/p` 這頁刻意不收題目
- 不要公開個人名次
- 不要在課堂解釋數字的來源，數字在教材頁面上有出處

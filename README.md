# 數位插畫與動態繪本創作

靜宜大學 115 學年度第 1 學期的合授課程網站，給修課學生與路過的讀者。

線上看：https://gloomcheng.github.io/115-digital-illustration/

第一週你會拿一個身邊的物件開始，先說出自己看見了什麼，再把它變成可以比較的畫面。後面才接風格、工具、角色、場景、分鏡和動圖。每一次試做都留下原始版本、改動的位置和下一個問題，最後才知道作品是怎麼長出來的。

## 課程在做什麼

- 先把畫面放在一起比較，指出它讓人先看到什麼、漏掉什麼。
- 把風格拆成線條、形狀、色彩、材質、空間與用途。
- 拿同一個工作在不同工具裡跑一次，記下額度、格式和卡住的位置。
- 用提示詞與畫面說明反覆試做一個視覺方向。
- 將角色、場景與版面整理成別人接得下去的作品包。
- 從畫面要放在哪裡、誰會先看到、能不能延伸與素材來源檢查一個 IP。

## 誰帶哪一段

這門課兩位老師一起帶。AI 工具這一段教你挑工具、寫畫面說明、拆風格、快速試誤，最後整理成作品包；故事與分鏡那一段帶故事腳本、分鏡和鏡頭語言。網站每週標出誰帶，後半段你把分鏡條件轉成 AI 資產實驗。

## 這學期怎麼走

完整進度請看網站中的「課程進度」。從導航列進入課程進度、風格怎麼看、工具怎麼選、動圖怎麼做和作品怎麼交。

前 8 週先把畫面拆開來看，也習慣留下每次試錯。第 9–10 週接上故事、分鏡和鏡頭語言。第 11–16 週把分鏡轉成角色、場景和版面，最後整理成作品交接包。第 17–18 週再到展演和數位圖書館看看，作品離開課堂後會遇到什麼。

## 想自己架站或改網站

```bash
bun install --frozen-lockfile
bun run dev
```

開啟 `http://localhost:4321/115-digital-illustration/`。送出前先跑 `bun run quality`，把檢查、型別、建置一次驗完。

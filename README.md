# 數位插畫與動態繪本創作

靜宜大學 115 學年度第 1 學期的合授課程網站。

這門課從數位插畫與動態繪本開始。你會用 AI 工具觀察風格、提出視覺問題、快速試做，再把選擇與失敗整理成可以發表的作品。你不用先會 Illustrator 或 Photoshop；先把想法說清楚，再看工具如何回應。

## 課程在做什麼

- 先看人工智慧替你做了哪一段，再決定自己要補哪一段。
- 把風格拆成線條、形狀、色彩、材質、空間與用途。
- 比較不同 AI 工具和免費方案到底差在哪裡。
- 用提示詞與畫面說明反覆試做一個視覺方向。
- 將角色、場景與版面整理成別人接得下去的作品包。
- 從觀眾、媒材、延伸性與權利來源檢查一個 IP。

## 合授分工

你會負責 AI 工具、提示詞、風格觀察與快速試誤；另一位老師負責故事腳本、分鏡和鏡頭語言。網站會標出每週由誰帶，後半段再把分鏡條件轉成 AI 資產實驗。

## 這學期怎麼走

完整進度請看網站中的「課程進度」。啟動本機網站後，從導航列進入課程進度、風格怎麼看、工具怎麼選、動圖怎麼做和作品怎麼交。

前 8 週先把畫面拆開來看，也習慣留下每次試錯。第 9–10 週接上故事、分鏡和鏡頭語言。第 11–16 週把分鏡轉成角色、場景和版面，最後整理成作品交接包。第 17–18 週再到展演和數位圖書館看看，作品離開課堂後會遇到什麼。

## 本機啟動

```bash
bun install --frozen-lockfile
bun run dev
```

開啟 `http://localhost:4321/115-digital-illustration/`。
